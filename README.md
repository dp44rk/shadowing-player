# Shadowing Player

유튜브 영상으로 영어 쉐도잉 연습을 하는 웹앱입니다. 모바일에서도 쓸 수 있도록 PWA로 만듭니다.

## MVP 목표

- 유튜브 링크를 넣으면 영상 재생
- 문장(구간) 단위 반복 재생 (A-B 루프)
- 재생 속도 조절 (0.5x ~ 1.25x)
- 모바일 브라우저에서 잘 동작하고 홈 화면에 추가 가능

## 이후에 해볼 것

- 문장별 자막 표시와 이동
- 내 목소리 녹음 후 원본과 번갈아 듣기
- 연습한 영상과 문장 기록
